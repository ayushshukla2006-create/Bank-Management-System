# Bank-Management-System

Bank-Management-System
Bank Account Management System Basic console banking app written in Core Java (OOP and Hash Map learning project) In this project‚ I wanted to learn: How to get comfortable with Java Object Oriented Programming How to store data in a Java Hash Map No GUI! Just console-based․ By the way‚ I did this Udemy course while making this project․ Features: Open a new account‚ putting your name and initial amount․ You will get an account number starting from 1001 (auto-increment)․ Deposit Money - based on your account number Withdraw Money - based on your account number Balance Enquiry - print current balance and account holder details Tech stack: Java (Core) Object Oriented Programming‚ Scanner‚ Hash Map‚ Switch-Case‚ etc․ How to run this project: Make sure you have Java (JDK) installed on your computer․

Download / Copy the file Bank App․java to your computer․
Then open terminal/command prompt and go to the folder where you downloaded the file․
Compile java file:
Run java application: Limitations / future scope: It does not save data - it's using Hash Map․ So‚ when you close the console‚ data will be lost․ Next‚ I will add File Input and Output feature (writing/reading to․txt or․csv file) to make the data persistent․ Handling input mismatch (e․g․ If user enters a letter instead of a number) is not added‚ which I will do in the future․
